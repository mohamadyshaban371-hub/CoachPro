# CoachPro (كوتش برو)

A comprehensive, Arabic-first Progressive Web App (PWA) for managing athletic training, nutrition, and EMS (Electrical Muscle Stimulation). Features deep integration with Google Gemini AI for plan generation, OCR (InBody analysis), and client coaching.

## Tech Stack

- **Frontend**: React 19, Vite 7, Tailwind CSS v4, Lucide React, Framer Motion
- **Backend**: Express (via `tsx`), Port 5000
- **Database & Auth**: Firebase (Firestore, Auth, Storage)
- **AI Engine**: Google Gemini (via `@google/generative-ai`), Flash 1.5/2.5 models
- **Package Manager**: pnpm

## Running the App

The workflow command is:
```
pnpm install --ignore-workspace && PORT=5000 pnpm dev
```

This installs dependencies (if missing) and starts the Express + Vite dev server on port 5000.

## Architecture

- `server.ts` — Express server: Firebase Admin SDK, Gemini AI proxy, file upload/storage endpoints, Vite middleware
- `src/` — React frontend
  - `components/` — All UI views (Login, Onboarding, ClientDashboard, AdminDashboard, surveys/)
  - `lib/` — Business logic (aiBlocks, scientificEngine, emsProtocol, gamification)
  - `services/aiMasterEngine.ts` — Central Gemini AI orchestrator
  - `firebase.ts` — Firebase client SDK configuration
  - `types.ts` — TypeScript interfaces
- `firebase-applet-config.json` — Firebase project config (non-secret, client-side safe)

## Required Secrets

All configured as Replit secrets:
- `GEMINI_API_KEY` — Primary Google Gemini API key
- `GEMINI_API_KEY_2` — Backup Gemini API key (failover on quota)
- `FIREBASE_SERVICE_ACCOUNT_KEY` — Firebase Admin SDK service account JSON

## Key Features

1. **Onboarding**: Multi-step registration with InBody photo OCR via Gemini AI
2. **Admin Dashboard**: Coach console for managing clients, packages, and generating AI plans
3. **Client Dashboard**: 9-tab hub (Today, Weekly, Analysis, Chat, Falcon, Feed, Profile + Assessment/Injury tabs by membership)
4. **AI Plan Generation**: 7-day personalized workout + nutrition plans linked to Scientific Engine
5. **Surveys**: Nutrition, Workout, Rehab, and EMS specialized forms with welcome card
6. **Gamification**: XP, ranks, badges, and coins system
7. **EMS Protocol**: Safety rules and intensity translation for electrical muscle stimulation
8. **Membership Registry**: ALL package types (EMS, Workout, Nutrition, Rehab) use registry dropdown in activation + renewal modals
9. **Financial Dashboard**: Full payment tracking with installments, status, and client membership assignment
10. **Real-time Unread Messages**: Admin nav shows live badge counter for unread client messages
11. **Smart Physical Assessment**: EMS/Workout → fitness tests via Adaptive Testing System; Rehab-only → injury assessment (ROM, pain, stability, strength, function) from REHAB_TESTS library
12. **Android APK**: Capacitor wraps the web app; GitHub Actions workflow auto-builds debug APK on every push to `main`

## Android Build

- **Method**: Capacitor 8 wraps the existing React/Vite PWA
- **Config**: `capacitor.config.ts` — appId: `com.coachpro.app`
- **Workflow**: `.github/workflows/build-android.yml` triggers on push to `main`
- **Download APK**: Go to GitHub → Actions → latest run → download `coachpro-android-apk` artifact
- The `android/` directory is NOT committed (generated by CI from `npx cap add android` + `cap sync`)

## Firebase Structure

- `users/{uid}` — User profiles with role (admin/client)
- `questionnaires/{uid}` — Survey responses
- `measurements/{uid}` — Body measurements
- `client_uploads/{uid}` — Uploaded files
- `memberships/{id}` — EMS membership tiers (name, price, sessions)
- `clientMemberships/{id}` — Client subscription records with payment installments
- `emsSessions/{id}` — EMS session check-in records

## UI/UX Rules

- Physical Assessment tab in ClientDashboard only shows after `profile.questionnaireComplete === true`
- SurveyManager shows: welcome card → surveys (one per package) → completion. Guards for empty packages & undefined currentSurvey prevent crashes
- Admin dashboard: Firebase Storage banner removed; "طلب تقييم بدني" button/modal removed; sounds on bell/refresh/messages buttons; unread badge on messages icon
